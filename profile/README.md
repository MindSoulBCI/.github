# MindSoul脑机接口的操作系统（BCI基座大模型）

**成都（上海）脑云矩阵科技有限公司**

Transformer-based neural decoding, non-invasive brain–computer interfaces and spatial computing.

MindSoul 团队研究脑机接口操作系统、Transformer 神经解码模型、多模态标注与跨平台交互。模型介绍已发布；权重、评测与客户端源码按路线图逐步公开。
